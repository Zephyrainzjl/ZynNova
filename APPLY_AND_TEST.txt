ZynNova TetGen Windows editable-install fix
==========================================

Root cause
----------
The previous cpp/CMakeLists.txt unconditionally installed
cpp/third_party/tetgen/README.md even though that file was not included in the
previous patch. TetGen itself compiled and linked successfully; CMake failed
only during the wheel staging/install step.

Apply from the ZynNova repository root (PowerShell)
---------------------------------------------------
Expand-Archive .\ZynNova_TetGen_Windows_Install_Fix.zip -DestinationPath .\_fix
Copy-Item .\_fix\ZynNova_TetGen_Windows_Install_Fix\* . -Recurse -Force

Clean the failed build cache
----------------------------
Remove-Item -Recurse -Force .\build\cp312-cp312-win_amd64 -ErrorAction SilentlyContinue

Reinstall
---------
python -m pip install -e ".[zynmorph-tetgen]" -v

Smoke test
----------
python -c "from zynnova._native import _zynmorph_tetgen_native as m; print(m.__doc__)"
python -c "from zynnova.zynmorph.tetgen import tetgen_native_status; print(tetgen_native_status())"

Regression test
---------------
python -m pytest -q tests/zynnova/test_zynmorph_tetgen_build_contract.py tests/zynnova/test_zynmorph_tetgen_surface.py
