# ZynNova Python package

`zynnova` is the sole public namespace for the complete framework. Retained materials
science, simulation, and learning modules coexist with the independent `zynmorph`,
`zynvista`, `zynform`, and `zynvox` subframeworks. Shared difficult-task infrastructure
is provided by `core` and `geometry`; heavyweight model repositories remain isolated
behind the contracts in `BACKEND_CONTRACTS.md`.

Run `python -m zynnova status` for side-effect-free backend diagnostics.
